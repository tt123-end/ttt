# 猎手 v1.64：反馈修复版

在v1.63兼容版上处理本轮五项反馈及英灵剑补充要求；本轮反馈优先于此前表格中对应的单项数值。

1. 死亡之眼：修复换弹中被丢弃的原生额外泪弹仍能触发原生落空重置的问题。所有里猎手相关泪弹先关闭独立落空重置，再判断保留或移除；分裂弹继续共用原始攻击组。有效敌人接触/命中时立即记录组命中，不再只依赖帧末HP下降，避免静止靶回血或重设HP漏记。整组全部落空时只尝试一次原生重置，保留原生概率；不会人为锁死死亡之眼。

2. 原生蓄力圈：硫磺火、巧克力牛奶等已改成即时攻击的武器不再显示原生蓄力圈。换弹圆圈是独立绘制，不受这个开关影响。原版没有逐角色隐藏原生蓄力圈的接口，因此在里猎手持有相关道具并处于自定义即时攻击模式时临时关闭Options.ChargeBars，退出模式、死亡、结束本局、退出游戏或卸载MOD时恢复原设置。联机中这段时间其他角色的原生蓄力圈也会隐藏；其他角色的攻击及充能不变。

3. 胎儿博士：使用普通ENTITY_TEAR飞刀，不调用FireBomb来发射主攻击；清理原生炸弹附加标记，屏蔽漏出的原生胎儿炸弹（普通手动放置的炸弹不受影响）。飞刀仍为普通400%面板伤害；命中敌人、墙或障碍物爆炸，爆炸改为200%面板伤害+30。保留原生射速惩罚。

4. 吐根：普通直线飞刀，清除其原生爆炸标记和弧线下落参数，不继承炸弹/蓄力武器的单发伤害。单独持有吐根时，飞刀和爆炸各为100%面板伤害，爆炸可自伤；保留面板原生+40和射速惩罚。飞行中保持零下落速度/加速度并按面板射程计算行程，防止过早落地。普通飞行耗尽射程不会在空中额外爆炸。明确持有泪血症时仍保留泪血症自身的抛物线/分裂兼容。

5. 三圣颂：保留原生光束弹与原生相对伤害；对真正造成伤害的光束命中应用4倍，不再只修改可能被附属激光忽略的泪弹载体。初次命中、附属激光和可追溯分裂子代均处理；递归保护防止4倍重复相乘，毒火DOT及其他血激光不套此倍率。

6. 英灵剑：保留飞刀与满血原生剑气；在非换弹时间内每次实际出手时触发一次蓄力旋转斩击。长子权两发分别触发旋转斩击，开始换弹不再额外触发。

同时拥有胎儿博士+吐根时，沿用此前单独确定的组合方案：主飞刀100%面板、爆炸100%面板+30、普通射速上限0.6、免疫爆炸；本轮未自行重写该明确组合规则。伤害道具的其他明确自定义联动继续按其兼容规则处理。

EID道具中英文同步以上数值和触发时机。人物贴图/动画、表猎手代码、初始数值、Stats+倍率与原有普通容器红心/骨心豁免保持v1.63。

本地验证：确认v1.63在两项死亡之眼缺陷及三圣颂附属激光回归场景失败；v1.64通过相同场景。通过240轮静止靶连续命中、寄生虫整组命中/全落空、普通泪弹实体/完整行程/空中消失、原生胎儿炸弹拦截与手动炸弹隔离、光束首次/多次/子代实际伤害4倍及DOT隔离、长子权两次出手旋转斩击、蓄力圈开关恢复和换弹圈绘制模拟。Stats+原上传API、EID原上传API、210组射速单调性、原红心/骨心回归、Lua语法及XML/ANM2解析检查通过。

尚未运行Isaac游戏；上述为Lua逻辑与引擎接口模拟，不是游戏实测。原生英灵剑Spin实体碰撞、原生光束来源回调、其他MOD改写伤害/弹道的复杂组合仍需要游戏确认。磐石安全精确只读上限等此前限制不在本轮修改范围。

安装：退出游戏，备份并移出旧版猎手，将ZIP内zzzz_revolver_samson文件夹解压到mods。不要同时启用多份猎手。原版忏悔可用，不要求REPENTOGON。
