## 减罚函数

令 M 为道具原本的负射速倍率合乘结果（依照原版的优先级、互斥和覆盖关系）。没有相关道具时 M=1，惩罚越重 M 越小。

**普通射速软上限 C(M) = 0.6 + 0.4 × M**

|原本合乘负倍率 M|新普通软上限 C|
|---:|---:|
|1|1.000|
|0.66|0.864|
|0.50|0.800|
|0.42|0.768|
|0.10|0.640|
|0.01|0.604|
|趋近 0|趋近 0.600|

因此普通软上限从 1 平滑下降，并始终不低于 0.6。0.6 约束的是**普通软上限**：低基础射速下，实际射速仍可以低于 0.6；突破软上限的增益仍然可以使实际射速超过 C(M)。

计算流程：先从引擎已计算的射速中还原已识别的原版负倍率，再进行基础射速校准、乘角色 ×0.2，最后把原负倍率惩罚替换为 C(M)/1。实际射速不被强行钳制到 0.6 或 C(M)。

为同时满足“基础射速 2.4”和“普通软上限 1”，校准曲线固定两个点：原生初始射速 30/11 对应修正前 2.4，原生普通软上限 5 对应修正前 5。两点间连续线性连接，超过原生软上限时继续延伸，保留突破效果；初始及更低数值区间保持原有基础校准比例。

- 胎儿博士使用正确的 ID 52；ID 168 为史诗胎儿，不再错误当作胎儿博士。
- 识别硫磺火、吐根、泪血、大眼、三眼、四眼、怪兽的肺、夏娃的睫毛及科技 2 的相应负倍率；保留道具间优先级与非叠加组。
- 泪血/吐根按同组负倍率处理；科技 2 使用 Repentance 的 ×2/3。
- 保留 20/20、剖腹产等覆盖规则；剖腹产不会顺带抹掉另外持有的四眼惩罚。
- 同时查询实际持有物和临时道具效果。模组新增或自行改写射速的道具需要按其具体实现补充识别。

道具 ID 与单项倍率对照 IsaacDocs 枚举及 EID Repentance 说明校对；复杂组合的原版实际行为仍需游戏内验证。
