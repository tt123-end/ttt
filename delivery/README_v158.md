# 猎手 v1.58：里猎手 EID 角色特性说明

[下载完整猎手 Mod](hunter_v158.zip) · [查看说明文本](eid_character_text_v158.txt) · [验证记录](validation_v158.json)

为里猎手加入 EID 角色特性说明，支持简体中文和英文。使用上传的 external item descriptions_836319872 版本公开的 addCharacterInfo 接口，沿用表猎手的注册方式与显示入口。

中文说明如下：

- 单发泪弹造成角色面板攻击力 800% 的伤害。
- 每次攻击后进入换弹，持续 1 个攻击间隔。
- 换弹期间受到的伤害翻倍。
- 非主动付血型伤害实际扣到红心时，每次增加 1 颗碎心。
- 献血机、恶魔乞丐、献祭刺、诅咒房刺门等不触发碎心。
- 巨人独眼式伪穿透：击杀后保留剩余伤害继续飞行。
- 受到的负射速倍率惩罚减轻。
- 普通射速软上限由 1 趋近 0.6，不保底实际射速。

“非主动付血型”对应当前碎心判定：生命交易/付血交互免除碎心，普通战斗、意外爆炸和普通环境失误按原规则判断。实际扣血规则与 v1.57 相同，本版只增加说明。

## 查看与安装

保持原 EID Mod 启用，退出游戏后备份并移出旧版 zzzz_revolver_samson，将本压缩包中的同名文件夹解压至 mods。EID 本体继续使用原文件，无需覆盖或重新配置。

在 EID 的物品回顾（Item Reminder）中查看角色特性分类。通常按住地图键（键盘默认 Tab），按 EID 的导航设置切换至角色页；入口和按键沿用 EID 当前配置。

中文页面角色名为“里猎手”，英文页面为“TAINTED HUNTER”。表猎手原说明仍由原 mod_compat.lua 独立注册。已处理 EID 晚于猎手加载、暂时缺少 API、API 实例替换与重复注册。

## 验证范围

执行了上传 EID 原文件中的角色注册、语言选择、描述读取及 Item Reminder 角色页路由函数，确认中英文内容按对应里猎手 ID 读取，表猎手原说明未被覆盖；也检查了未启用/延迟启用、重复更新与无效角色 ID。

本版玩法、数值、碎心判定、外观、起始配置和 Stats+ 文件保持 v1.57 原字节内容，仅新增 EID 说明模块和入口。10 个 Lua 文件语法及 XML/ANM2 解析检查通过。

尚未游戏内实测，EID 字体及实际排版需要局内确认。验证过程使用实际 EID 接口源码和最小游戏接口模拟，并非游戏截图或游戏运行测试。
