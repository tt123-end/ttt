# 猎手 v1.60：泪血症＋硫磺火射速补偿修复

旧代码把泪血症与吐根共用一个惩罚分支，在硫磺火分支中仅补偿了一次1/3，漏掉泪血症的额外惩罚。现在该组合按1/9的负倍率进行补偿；硫磺火＋吐根原有的优先级规则保留。

曲线仍是 C(M)=0.6+0.4M，M为适用的原生负射速倍率。按这组道具的模型，普通射速软上限约为0.6444；继续叠加适用的负倍率时趋近0.6。

0.6是普通射速软上限的下界，不是当前面板射速的保底：未拿射速道具时初始0.48保持不变，该组合在起始射速模型下约0.3093。测试软上限时，需要继续增加普通射速直至不再增长；突破软上限的加成仍可继续提高射速。

本版保留v1.59的0.75伤害修正。角色外观、碎心、换弹、800%单发伤害、起始物品、Stats+和EID文本保持原样；不需要安装REPENTOGON。

已用独立指定的原生延迟模型用例确认旧版失败、新版通过，覆盖组合叠加、射速道具增长、移除道具及临时效果。原属性/Stats+测试与Lua、XML检查通过。这里的原生延迟是模型用例，不是游戏采样；当前没有游戏运行环境，用户报告的0.27和实际组合上限仍需局内复测。
