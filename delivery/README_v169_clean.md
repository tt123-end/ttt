# 猎手 Hunter — v1.69

当前整理版包含表猎手、里猎手的运行代码及所需人物、动画和UI资源，支持现有Stats+与EID适配。

本包仅清理历史说明、验证记录和未使用的旧素材。运行代码、道具机制、数值、人物外观与仍在使用的动画/贴图均保持v1.69原样。部分必需资源沿用带版本号的文件名，请勿按文件名中的数字自行删除。

安装：完全退出游戏，先将旧zzzz_revolver_samson文件夹移出mods备份，再把本包同名文件夹完整解压到mods，只启用一份猎手。请完整替换；直接覆盖不会删除旧文件。不要删除游戏data目录或自己的存档。

使用当前匹配忏悔+的REPENTOGON Launcher启动游戏。控制台hunterdiag显示的版本仍为v1.69，本次清理不升级机制版本。

REPENTOGON官方启动器：https://github.com/TeamREPENTOGON/Launcher/releases/latest
官方安装/存档说明：https://github.com/TeamREPENTOGON/REPENTOGON/blob/1.1.3/docs/docs/install_zh.md
