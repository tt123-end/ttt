# 猎手 v1.65：概率落空、完整旋斩与原生牛奶移除

本版依据本轮四项视频反馈及剖腹产补充修改，死亡之眼按你确认的选择保留原版概率重置。

1. 死亡之眼：死亡/已不存在的弹体不再依赖“移除回调”才能退出一轮。按实际存活状态重新统计原弹及子代，清理卡在待机动画的死亡飞刀；子代尚存时不提前结算。整组全部落空后只调用一次原版ClearDeadEyeCharge，保留原版概率，不能要求每一次落空都必定清空。敌人、仍燃烧的火堆和碰撞到的大便计为命中；普通墙体及空中射程耗尽属于落空。

2. 英灵剑：每次非换弹期间实际出手触发完整360度旋斩，满血剑气保留。原版Lua没有设置原生旋斩内部状态的接口，本版用原生剑素材独立绘制，直接驱动一周旋转和扫过区域的碰撞；隐藏、禁用用于取素材的普通剑实体碰撞，避免再额外普通砍一下。旋斩伤害8×面板+10，同一周对每个敌人只命中一次，保留反弹敌弹处理。长子权两次出手分别触发，开始换弹不追加触发。具体原生素材的动画帧、朝向及与视频参考的视觉接近程度尚需进游戏确认。

3. 三圣颂：在v1.64设定倍率上再乘4，本版目标为原版光束实际命中伤害×16。扩展附属光束和直接报告玩家来源的命中追溯。倍率处理提前到普通伤害观察回调之前，避免测试靶先读取/取消未加成伤害；加入递归保护，普通毒火DOT及其他独立血激光不重复放大。更高优先级或完全改写攻击来源的其他MOD仍需实测。

4. 巧克力牛奶：里猎手实际拾取后，原版道具69替换为专用被动Hunter Chocolate Milk，强制刷新武器与射速缓存，原生牛奶的蓄力和点按攻击能力退出。该替代被动只保留此前确定的伤害函数：1.2+2.8×((1-clamp(当前射速/最高射速,0.25,1))/0.75)^2；比例≤0.25时×4，比例1时×1.2。正常攻击间隔、弹仓与装填继续生效。无来源标记的原生额外攻击不能通过CanTriggerStreakEnd=false绕过脚本弹仓。临时牛奶效果在创建受控主弹时隔离并恢复，异常退出同样恢复；永久道具通过专用被动移除原版逻辑。角色转换为其他类型时恢复原道具。专用被动正常存于原生装备中，续玩不重新发放；它的内部ID与原道具不同，第三方直接按HasCollectible(69)检查的行为需另行兼容。

5. 剖腹产：携刀胎儿形态和兼容效果保留，实际攻击伤害乘以v1.64的0.25。倍率在实际受伤结算应用，原弹、派生子弹、胎儿刀及子激光均只削减一次；不在父弹和子实体上重复相乘。独立神性光环、毒火DOT等其他道具副效果不额外削减。无其他特殊增减时，相当于从原兼容4倍原生攻击伤害降为1倍。

EID中英文同步上述机制与数值，专用巧克力牛奶被动也注册说明。初始数值、Stats+倍率、普通容器红心/骨心豁免、人物图像与动画资源、表猎手均未修改。上一版其他明确兼容规则保留。

验证：v1.64的“死亡但未移除导致不结算”“原生false-streak牛奶攻击漏过装填”“普通优先级测试靶先取消伤害导致倍率回调不运行”在本地回归模型中复现；v1.65通过同类场景。通过整组概率重置调用次数、延迟子代、火/大便/墙体分类、190次连续点按与蓄力释放拦截、牛奶替换及武器缓存刷新、临时效果异常恢复、四个方向旋斩实际命中且范围外不命中、剖腹产多种攻击来源只削减一次、三圣颂普通/子代/玩家来源16倍和取消式靶子观察顺序。Stats+原上传接口、EID原上传接口、210组射速单调性、红心/骨心旧回归及Lua/XML/ANM2检查通过。

没有Isaac运行时，以上属于逻辑/接口模拟与上传视频分析，不是游戏实测，也不表示所有道具组合已经验证。尤其旋斩素材显示和其他MOD的光束来源需要游戏验证。磐石精确只读上限等此前已说明限制不在本次修改范围。

需要定位时可选用控制台命令hunterdiag：native_miss_requests表示已向原版提交概率重置的轮数，并非必定清零次数；native_milk应为0、logical_milk是专用被动对应份数；light/fetus显示倍率前及提交倍率后伤害，最终扣血还会受原生护甲影响。命令仅在主动输入时输出，不添加游戏内UI。

安装：退出游戏，备份并移出旧版猎手，将ZIP内zzzz_revolver_samson文件夹解压到mods；不要同时启用多份猎手。本版可用于原版忏悔，不要求REPENTOGON。已有巧克力牛奶的里猎手续玩后自动替换为专用被动。
