# 猎手v1.69：当前忏悔+／REPENTOGON环境

使用匹配忏悔+的官方Launcher，不要混装普通忏悔1.0.12 DLL。

- 官方Launcher：https://github.com/TeamREPENTOGON/Launcher/releases/latest
- 官方安装和存档说明：https://github.com/TeamREPENTOGON/REPENTOGON/blob/1.1.3/docs/docs/install_zh.md
- Weapon接口：https://github.com/TeamREPENTOGON/REPENTOGON/blob/1.1.3/docs/docs/Weapon.md
- 回调说明：https://github.com/TeamREPENTOGON/REPENTOGON/blob/1.1.3/docs/docs/enums/ModCallbacks.md

退出游戏并完整替换猎手旧文件夹，只启用一份。hunterdiag应显示[Hunter v1.69] REPENTOGON=true。本版三圣颂实际伤害为原版4倍，不再使用历史版本BaseDamage=67.2的检查；英灵剑诊断报告真实Spin观察结果及原生武器/输入调用计数。

本机没有运行Isaac；原生旋斩仍需游戏确认。详细修改以本包修复说明v1.69为准，其余机制沿用v1.68。
