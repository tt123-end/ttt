# 猎手 v1.55：里猎手单发换弹机制第一版

[下载完整 Mod](hunter_v155.zip) · [弹体和换弹圈预览](hunter_v155_combat_preview.png) · [换弹圈动画](reload_circle_v155.gif) · [验证记录](validation_v155.json)

本版在已确认的 v1.54 数值上加入以下机制：

1. 初始炸弹从 1 改为 **0**。仅修改原生新开局配置；不会删除旧存档中已经拥有的炸弹。
2. 里猎手弹体采用新的高清钢制飞刀，保留表猎手飞刀的朝向与基本造型。源贴图密度为原先的 4 倍，补偿动画缩放以避免素材分辨率误改大小；在此基础上将飞刀视觉尺寸、初始碰撞半径分别乘 **1.5**。弹体方向跟随飞行速度，尺寸继续随原生泪弹缩放变化。
3. 改为 **每次攻击后换弹**，换弹时长为这次射击时的 **一个攻击间隔**，即 `max(1, ceil(MaxFireDelay + 1))` 个游戏帧。与原版射击冷却并行，不额外叠加一次间隔。采用表猎手原有 `chargebar.anm2/png` 的蓄力圆圈和完成闪烁；左下角以一把飞刀表示单发弹药，换弹时变暗。多重射击同一轮共用一次换弹，道具产生的后续泪弹不重置或延长这次计时。
4. 每颗直接由角色发射的泪弹，初始伤害为 **发射时角色面板攻击力 ×6**。当前开局面板 5.25，因此单发初始伤害为 **31.5**；面板数值本身不乘 6。
5. 添加原版巨人独眼使用的 **TEAR_PERSISTENT**：击杀敌人后若还有伤害余额，泪弹保留余额继续向前飞行。伤害扣减、碰撞与击杀由游戏原生处理，不主动添加无限穿透，也不会在后续更新中把剩余伤害重新补满。原有道具泪弹效果标志保留。
6. 换弹尚未结束时，承受的实际伤害 **×2**：原本半颗心变一颗心，原本一颗心变两颗心；结束当帧恢复正常。通过原版受伤接口重新提交一次双倍伤害，保留原伤害标志、来源、无敌时间与护盾处理，使用递归保护避免无限触发。纯假伤害不变为实际扣血。

开局射速仍为 0.60，因此初始换弹是 50 个游戏帧，约 **1.67 秒**；射速变化会影响下一次换弹时长。换弹期间只阻止四向射击输入，移动不受影响。

人物身体/头部/动画/斗篷、v1.53 的变身恢复、v1.54 的基础数值、死亡之眼、“皇帝？”及 Stats+ 兼容保留。表猎手原有四发机制和素材不变。新机制放在独立的 `tainted_hunter_combat.lua` 中，不要求 REPENTOGON。

## 验证范围

已检查单发/多发与后续泪弹、精确计时边界、不额外延长原版 FireDelay、逐泪弹一次性伤害/尺寸修改、原生持久泪弹标志以及剩余伤害不会被更新代码覆盖。受伤模拟覆盖半心/整心、递归保护、原伤害参数保留、护盾、无敌时间、其他回调取消与假伤害；还检查了其他角色/跟班隔离、多人状态分离、暂停/隐藏显示与素材失败回退。

重新执行了上一版基础数值和上传 Stats+ 实际校验器/Middleware 检查。7 个 Lua 文件语法、XML/ANM2 与新弹体裁切检查通过；原有 152 个文件（除主入口、版本说明与初始炸弹配置外）保持原字节内容。

以上为本地 Lua 引擎接口模拟和离线图像/配置检查，**尚未游戏内实测**。巨人独眼实际命中后的剩余伤害处理交由原版引擎，离线模拟不能替代游戏内连杀测试。预览是素材/ANM2 合成，不是游戏截图。

## 安装

退出游戏，备份并移出旧版 `zzzz_revolver_samson` 文件夹，将压缩包中的同名文件夹解压到 `mods`，避免同时启用多个版本。请新开一局里猎手确认初始炸弹为 0；继续旧局时不会强行清除现有炸弹。
