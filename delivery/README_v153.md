# 猎手 v1.53：拾取头身连接、变身退出后恢复本体

[下载完整 Mod](hunter_v153.zip) · [拾取前后对比](hunter_v153_pickup_comparison.png) · [拾取动画](pickup_v153.gif) · [验证记录](validation_v153.json)

本版处理两个问题：

1. 举起道具时保留 v1.52 的仰视眼睛、惊讶张嘴和举手动作，修复头身脱节。身体按原生遮挡顺序分成头部后方的躯干与头部前方的双臂，让头部回落到胸口连接处。只分配已有像素的绘制层，不重画或缩放身体；原身体、手臂、腿和绷带的颜色、形状及动作位置均保留。
2. 增加变身结束后的外观恢复。旧逻辑只在动画文件名变化时重载，无法处理文件名仍为猎手、内部图层却被皮肤/套装流程重置的情形。新版观察白火 Lost 效果、角色类型、套装状态、道具及临时外观效果退出，并重新恢复猎手各个图层。恢复后仅追加两次贴图绑定以处理稍晚到达的引擎清空；这两次不重启动画。稳定状态不反复加载，白火 Lost 期间保留引擎外观；新变身会取消旧的延迟恢复。外部特殊动画暂不接管，回到本体动画后再恢复。

普通正脸、背面和披风、碰撞、属性和普通猎手玩法沿用上一版。道具举起的位置和动画时长不变。本版使用原版 Repentance API，不依赖 REPENTOGON。

验证：10 个持物身体单元分层前后逐像素一致；97 帧不含头部的持物动作合成与上一版一致；其他动作 702 帧合成与上一版一致；600 条裁切有效；4 个 Lua 文件语法通过。使用实际旧版/新版适配器进行模拟，旧版重现同文件名贴图被清空后不恢复的问题，新版通过套装退出、白火效果退出、角色类型返回、临时效果/道具移除、延迟清空、重复变身、双人状态隔离和特殊动画保护检查。

已查看用户上传的两个游戏视频，但此环境没有游戏运行时。上述验证是离线 PNG/ANM2 合成和 Lua 模拟，不是游戏内实测；预览中不包含由游戏绘制的举起道具。

安装：退出游戏，备份并移出旧版 zzzz_revolver_samson 文件夹，再将压缩包中的同名文件夹解压至 mods；避免同时加载多个版本。
