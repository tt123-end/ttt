# 猎手 v1.57：红心受伤增加碎心，支付生命类交互免罚

[下载完整 Mod](hunter_v157.zip) · [验证记录](validation_v157.json)

里猎手新增：**一次非排除来源的受击实际损失红心后，增加 1 颗原版碎心。** 按受击次数计算，不按扣掉几颗心计算；换弹期间双倍伤害仍只算一次，增加 1 颗碎心。

|情况|增加碎心|
|---|---|
|敌人碰撞、敌人弹幕实际扣到红心|1 颗/次|
|普通地刺、火焰、爆炸等非免罚伤害实际扣到红心|1 颗/次|
|仅魂心或黑心受损|不增加|
|圣斗篷等护盾挡住、无敌帧免疫、伤害被取消、假伤害|不增加|
|骨心内的红心实际受损|1 颗/次|
|仅空骨心外壳受损，红心没减少|不增加|

## 不触发碎心的伤害

- 献血机。
- 恶魔乞丐。
- 献祭房的献祭刺。房内敌人攻击仍属于正常受伤，不会因为身处献祭房而全部免罚。
- 诅咒房刺门，进入和离开均按对应伤害标志排除。
- 刺箱。
- 血袋，以及剃刀、血之权利、尖插头等使用原版红心支付标志的主动生命消耗。
- 地狱游戏、忏悔室等已识别的支付生命交互。
- 使用原版“无惩罚”伤害标志的扣血。

通过伤害标志识别，并为献血机、恶魔乞丐、地狱游戏、忏悔室增加来源实体识别。普通敌人攻击如果明确带有强制红心伤害标志，仍按真实敌人受击统计。

**这些排除项只免除新增碎心，原有换弹期间受到伤害 ×2 的规则保留。** 血量容器交易、直接修改血量的道具效果本身也不会仅因红心数量下降而被额外处罚。

## 碎心与保留内容

使用原版 `AddBrokenHearts(1)`。碎心由游戏管理生命容量和存档，跨房间、楼层保留，也允许通过原版机制移除；本模组不建立固定四心上限，不另外手动删除红心容器，不会在移除碎心后自动补回。

采用同一受伤处理入口统一处理换弹翻倍和碎心：保留原伤害来源、标志与无敌时间；通过递归保护避免一次伤害被翻倍多次或重复增加碎心。只对对应伤害事件的实际红心损失判定，支持短期延迟结算观察；不会用全局血量差将捐血、买恶魔交易或其他容器消耗误算成普通受伤。

v1.56 的数值及效果保留：射速修正 ×0.2、攻击力修正 ×1、单发伤害 ×8 面板、负射速减罚曲线、每发一个攻击间隔的换弹、子弹放大及剩余伤害续飞。人物外观、飞刀、蓄力圈、起始道具卡牌、零炸弹和 Stats+ 显示不变。表猎手原有代码保持原样。
