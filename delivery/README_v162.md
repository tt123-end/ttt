# 猎手 v1.62：骨心填充红心不触发碎心

里猎手现在仅在非豁免伤害实际扣到普通心之容器内的红心时，每次增加1颗碎心。骨心中填充的红心受伤、空骨心外壳受伤均不会触发；同时持有普通容器和骨心时，也按实际受损的红心归属判断。

原因为GetHearts()同时统计普通容器及骨心中的红心，旧版直接比较其总量，误把骨心填充受伤也算作红心惩罚。本版使用GetMaxHearts()限定普通容器红心量，并在骨心伤害结算后清除相关待处理事件，避免将后续血量变化错算为该次伤害。

换弹期间受到的伤害仍翻倍，包括骨心伤害；本次只豁免骨心的碎心惩罚。献血机、恶魔乞丐、献祭刺、诅咒房刺门等原有豁免保留。EID中英文均明确说明普通容器条件及骨心豁免。

v1.61数值和射速实现保留：角色伤害修正×1.2，单发400%面板伤害，初始射程12；外观及表猎手保持原样。

本地测试确认旧版在骨心填充红心场景失败，新版通过；覆盖仅有骨心、半填充骨心、多个骨心、容器与骨心混合、空骨心、换弹翻倍、延迟伤害结算、护盾及付血交互。原伤害/战斗回归和实际上传EID接口检查通过，11个Lua文件语法及XML/ANM2解析通过。尚未游戏内实测。

退出游戏，备份并移出旧版猎手，将压缩包中的zzzz_revolver_samson文件夹解压至mods，避免同时启用多个版本。
