# 猎手v1.69：仅调整英灵剑触发与三圣颂伤害

本说明优先于包内历史版本说明。用户环境为忏悔+＋REPENTOGON。本轮范围按要求限定为英灵剑和三圣颂，其余机制沿用v1.68。

## 英灵剑

收到的v1.68诊断是“native weapon released, but no spin callback was observed”。此信息只能说明没有观察到旋斩回调，不能证明原生武器真的完成了释放。检查旧代码发现准备蓄力后就在POST_PLAYER_UPDATE阶段把蓄力清零，并且在该阶段结束输入覆盖与发射窗口；如果原生输入缓存或武器处理发生在窗口之外，释放便可能没有被原生逻辑正确读取。另外，旧逻辑等待新的FireSword回调，没有覆盖已有主剑实体切入Spin状态的情况。

v1.69把朝向/按下/松开请求保留到完整输入与武器更新结束，在POST_UPDATE推进阶段、恢复射击限制。准备蓄力后不再提前清零，直到真实旋斩出现或请求取消才清理。保留原生主剑的初始化实体，检查真实GetIsSpinAttack状态，既接收FireSword回调，也识别已有剑实体进入Spin，不要求每次释放都重新生成实体。准备阶段的普通挥剑实体保持隐藏并阻止伤害，原生Spin一旦出现便恢复原生显示与碰撞；不会额外造成一次普通挥剑。仍由游戏处理旋斩素材、动画、碰撞和伤害，不复制贴图、不手动Play(Spin)、不设置伪旋斩状态、不另写范围伤害。

这些改动经过接口与时序模型检查，未在本机运行Isaac。输入先缓存、武器在玩家POST更新之后才处理、主剑复用是本轮覆盖的兼容边界，不能把模型结果当成游戏原生回调顺序或旋斩已成功的实测证据。

hunterdiag中的sword会显示原生Spin是否被观察到，及arm_calls、release_calls、input_polls、sword_callbacks计数。若超时，会报告具体阶段和上述计数；若观察到真实Spin，会报告“native spin observed”与原生动画名称，不再仅凭脚本推进阶段宣布已释放。

## 三圣颂

实际命中伤害倍率从v1.68的原版8倍降到4倍，伤害再减半，EID中英文同步。沿用已经确认生效的光束碰撞/ExtraSource伤害链，不改变光束样式、单段比例、命中频率或角色面板。无其他增伤时，原生输入1.4的单段由11.2改为5.6；其他既有道具额外倍率按原规则另算。

## 保持不变

诅咒之眼及自伤/刺门转场传送代码、科技400%主激光、死亡之眼分组概率判定、专用巧克力牛奶、剖腹产伤害削减、生命/碎心/骨心规则、初始数值、Stats+、换弹UI、人物贴图和动画资源保持v1.68。验证不只检查这些测试，还逐文件比对独立模块，并对完整兼容代码做排除本轮剑保护/三圣颂倍率/版本文本后的逐字对比。

## 安装与测试

完全退出游戏，备份并移出旧zzzz_revolver_samson，将本ZIP内同名文件夹完整放入mods，只启用一份猎手。通过匹配忏悔+的REPENTOGON Launcher启动，控制台hunterdiag应显示[Hunter v1.69] REPENTOGON=true。不要求重新创建长期存档，先在测试局验证。

本地通过Lua5.4语法、XML/ANM2解析、原有Stats+/EID上传接口、兼容和生命判定模型，以及本轮完整输入/武器更新、保留蓄力、复用主剑、准备动作无伤害、原生Spin恢复碰撞、弹药/换弹/输入/射击限制恢复的检查。v1.68在提前清零蓄力及输入缓存/较晚武器处理的对应测试中失败，新版通过。没有Isaac运行环境，原版旋斩实际表现仍须游戏确认。

如仍无挥斩，提供v1.69的完整sword一行即可继续区分是否读取了输入、是否执行了武器更新、是否创建或复用了剑实体。复杂武器优先级与此前磐石等限制不在本次范围。
