# 猎手 v1.61：里猎手射速修复与数值调整

## 本版数值

角色伤害修正改为×1.2，初始面板伤害4.2；每发造成面板伤害的400%，初始单发16.8，死亡之眼满层时33.6。初始射程12，弹速1.6。初始射速仍为0.48，普通最高射速仍为1。

Stats+的角色伤害倍率使用同一配置，显示x1.20；角色射速倍率显示x0.20。EID中英文介绍均已改为400%面板伤害。

## 射速修复

v1.60通过手写倍率猜测泪血症与硫磺火的组合，再除掉猜测的惩罚。这会把带有额外延迟的组合补偿过头，出现拾取负射速道具后当前射速反升。

本版移除这套道具倍率表，采用上传Stats+的原生上限探测思路：短暂增加普通射速提升，读取角色修正前的原生缓存最高射速，随后完整移除新增的测试道具。无需REPENTOGON，也不依赖启用Stats+才能工作。不会移除已有武器、扣血、给予初始物品或操作主动道具槽；持有Rock Bottom时不执行探测，避免永久抬高它记录的属性。

当实测原生最高射速r低于5时，新角色最高射速为C=0.6+0.4*(r/5)，从1向0.6收敛；r高于5时按r/5保留最高射速增长。当前射速使用剩余原生攻击延迟计算：30/(30/C+6.5*(当前原生延迟-原生上限延迟))。这一计算保持初始0.48、上限1；对于叠加乘法或额外延迟的原生惩罚，当前射速下降，上限向0.6收敛。

0.6约束Stats+实际探测的当前最高射速，不是当前射速保底；当前射速允许低于0.6。不会靠只修改Stats+显示文字来伪装修复。动态效果的上限可能在约3秒内刷新；道具/临时效果组合改变与换房会重新探测。

本地原生延迟模拟中，泪血症+硫磺火样例显示约0.27/0.66；由用户v1.60反馈的0.67/0.87反推的延迟样例修复后约0.258/0.658。这些均为测试模型和反馈派生数据，不是实际游戏运行结果，具体局内数值以原生探测为准。

## 安装与验证

退出游戏，备份并移出旧版猎手，将hunter_v161.zip中的zzzz_revolver_samson解压至mods，避免同时启用多个版本。继续旧存档会重算属性，不重复发放初始物品。表猎手、外观素材、换弹规则、碎心判定保持原样。

本地通过了210组延迟惩罚单调性检查、实际上传Stats+的computeTearCap与格式化函数、伤害中间件及EID角色页接口；也检查了原有测试道具留存、异常后清理、临时效果、联机角色隔离、继续存档、换弹/伪穿透等回归。11个Lua文件语法及XML/ANM2解析通过。

尚未游戏内实测。Rock Bottom持有时沿用上次测量的上限或默认参考；Stats+本身也会对该道具显示未知上限。其他Mod若监听普通测试道具的添加/移除，仍可能收到原生回调，与Stats+原有探测方法一样。
