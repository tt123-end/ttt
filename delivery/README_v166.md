# 猎手 v1.66：原版旋斩接口与三圣颂生成阶段增伤

本版仅处理英灵剑和三圣颂，保留你已确认正常的死亡之眼、专用巧克力牛奶与剖腹产。初始数值、Stats+倍率、生命惩罚和人物贴图/动画资源保持v1.65。

英灵剑：删除v1.65复制剑素材、额外绘制和脚本范围伤害；在REPENTOGON可用时，直接对原生EntityKnife调用SetIsSpinAttack(true)及SetIsSwinging(true)，由游戏本身处理原版旋斩的动画、碰撞体、命中列表和反弹。原生碰撞子刀保留，不再被普通主武器清理误删。满血剑气继续保留，仍在非换弹期间实际出手时触发旋斩。没有REPENTOGON或接口不可用时仅保留飞刀/满血剑气，不再用仿制挥砍充当原版旋斩。

三圣颂：目标仍为原版光束伤害的16倍，本轮不再提高这个数字。此前实现有明确缺口：载体被恢复成原生数值，只在Lua命中来源被成功识别后补乘；若原生伤害链使用创建时缓存的只读BaseDamage、或命中来源无法追溯，就可能继续使用原始伤害。现在由受控原生FireTear创建高基础伤害的弹体，倍率进入原生BaseDamage初始化阶段，后续原生光束/子代沿其相对比例继承；这些弹体不再额外执行16倍命中回调，避免重复增伤。仅在同步创建调用内提供倍率后的玩家伤害输入，返回或异常时立即恢复，期间不进行缓存重算或跨帧保留。角色面板及其他独立攻击保持原值。

初始面板4.2、没有死亡之眼/牙齿等单发加成时，目标BaseDamage为67.2。光束每段仍采用原生单段比例/频率，不代表每一段伤害都是67.2。此修复兼容普通忏悔，不要求REPENTOGON；需要REPENTOGON的是英灵剑原版旋斩状态接口。

安装REPENTOGON请看同包《REPENTOGON_安装说明.md》或发布目录中的REPENTOGON_install_v166_zh.md。已确认普通忏悔v1.7.9b.J835可使用官方REPENTOGON1.0.12，该版本有本次需要的两个旋斩接口；忏悔+请使用当前官方Launcher，不要混装两个系列的包。猎手ZIP没有夹带第三方DLL。

EID中英文同步本次机制。hunterdiag会显示原生旋斩接口状态，以及光束创建时的factor/BaseDamage/CollisionDamage，便于核对真正初始化的数值。

本地验证覆盖：v1.65在只读原生BaseDamage缓存路径中的未增伤回归；v1.66生成时16倍基础伤害、后续CollisionDamage被改写、命中来源为空、子代相对比例、面板及临时效果在成功/异常后的恢复；原生旋斩API状态、原生可见与碰撞属性、旧版1.0.12与较新版本碰撞子刀的保留、无接口时不再仿制；死亡之眼、专用牛奶、剖腹产及原生命伤害旧回归、Stats+和EID上传接口、Lua语法及XML/ANM2解析。获确认的独立模块保持字节一致。

没有Isaac运行时；以上是接口源码核对及逻辑/原生缓存模型检查，不能代替游戏实测。原版旋斩的实际动画、光束实际伤害与第三方MOD组合仍需在游戏确认。磐石精确只读上限等此前限制不在本次范围。

安装猎手：退出游戏，备份并移出旧版，将ZIP内zzzz_revolver_samson解压到mods，只启用一份猎手。REPENTOGON与猎手的安装位置不同，详见安装说明。
