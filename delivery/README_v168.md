# 猎手 v1.68：忏悔+／REPENTOGON反馈修正

本说明优先于包内历史版本说明。用户现已切换至忏悔+并启用REPENTOGON；本版以此为目标，所需接口已对照官方REPENTOGON1.1.3源码。本地没有Isaac运行环境，以下新增行为仍需游戏内确认。

## 本轮改动

英灵剑：用户hunterdiag已确认v1.67返回“original sword Spin animation unavailable”。普通FireKnife创建的实体没有原版Spin素材，过去把旋斩状态/动画写在这个实体上无法满足需求。v1.68不再调用FireKnife、不再手动Play(Spin)。实际出手后，为角色真实持有的Spirit Sword主武器安排一次原生蓄满释放：只在其原生玩家更新窗口内短暂提供朝向/松键输入及可发射状态，随后恢复输入和射击限制，不额外消耗弹药、不重新开始换弹。通过游戏的MC_POST_FIRE_SWORD接收真正的原生旋斩，原生负责素材、动画和碰撞。保护旋斩实体及其碰撞子刀；如果调用者在回调返回后才完成状态初始化，会等到实体首次更新再核对，避免误删。没有脚本范围挥砍、替代渲染、复制剑贴图或手动伤害。满血剑气保留。

这条原生释放路径仍需游戏验证。若主武器被其他道具替换而不再是Spirit Sword，诊断会明确显示主武器不可用，不用仿制挥砍代替。复杂武器优先级组合未在游戏逐一验证。

诅咒之眼：根据本轮补充，换弹期间的真实受伤应包含自伤。采用REPENTOGON实际受伤后的回调排队，不再用延迟血量比较与GetLastDamageFlags完全相等判定。非自伤和刺房门、献血机、恶魔乞丐、献祭、健康消耗等真实自伤均可触发；黑蜡烛仍阻止传送，假伤害和护盾取消的伤害不触发。原生蓄力传送仍被抑制，避免同一受伤重复传送。

刺门的受伤请求会保留到门后的房间，等待转场与玩家更新结束、房间稳定后再调用原生随机房间传送；不会在伤害回调或玩家更新中直接切房，不再借用主动道具使用链。使用正数随机种子，队列消费后才调用传送。其他换房、换层、死亡、失去道具或取得黑蜡烛会取消不再适用的请求。诅咒之眼的这条自伤传送规则与碎心惩罚完全独立：自伤不增加碎心的既有判定保持原文件不变。

三圣颂：保留用户已实测生效的实际光束命中增伤路径，倍率从16改成8，伤害减半。角色面板、原版光束单段比例与频率不变，EID同步。例如其他条件不变时，原生输入1.4的单段由22.4改为11.2；额外巧克力牛奶兼容增伤按原规则另算。

科技（道具68）：受控发射原生直线激光，遵守一发后换弹的机制；基础每次命中400%角色面板伤害。命中回调直接给出实际伤害，而不是仅改可能被原生缓存绕过的CollisionDamage字段，也不是在已400%的伤害上再乘4。基准面板4.2时为16.8；同时有巧克力牛奶时保留其额外倍率。支持精确碰撞归属和新版ExtraSource，阻止未授权的原生额外主激光。此次数值针对科技主攻击，不扩大到科技X环、硫磺火或其他辅助激光。

EID中英文同步科技400%、三圣颂8倍、诅咒之眼包含自伤。人物视觉资源、基本数值、Stats+、生命惩罚模块及剖腹产命中伤害削减保持既有版本。死亡之眼与专用巧克力牛奶的已确认规则保留。

## 安装与检查

完全退出游戏，将旧zzzz_revolver_samson移出mods备份，完整解压新包中的同名文件夹，只启用一份猎手。忏悔+通过对应REPENTOGON Launcher启动，不沿用普通忏悔1.0.12的DLL。先开测试局；不要求重新创建长期存档。

控制台hunterdiag应显示[Hunter v1.68] REPENTOGON=true。获得对应道具并使用后，还会报告：

- sword：原生武器排队、蓄满/释放、捕获到原生旋斩，或明确的失败阶段。
- cursed eye：受伤排队与随机传送请求。
- light：三圣颂实际incoming/applied伤害。
- technology：科技实际incoming/applied伤害。

如果英灵剑仍无动画，请发射一次后提供sword这一行；本版能区分真实武器不存在、未收到原生旋斩回调和原生旋斩已捕获。不要把“接口模型通过”当成游戏动画已经通过。
