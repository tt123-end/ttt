# 猎手 v1.67：忏悔龙报错、原版旋斩、三圣颂实际伤害与诅咒之眼

这份说明优先于包内历史版本说明。本版适配已安装REPENTOGON的环境；普通忏悔对应官方REPENTOGON1.0.12。人物外观、初始数值、死亡之眼、专用巧克力牛奶和剖腹产的已确认方案保留。

## 安装与版本确认

完全退出游戏，将原zzzz_revolver_samson文件夹先移出mods备份，再把新ZIP内同名文件夹完整放入mods。只启用一份猎手，不要把新文件夹嵌套在旧文件夹里。重新启动游戏，控制台输入hunterdiag，第一行应包含[Hunter v1.67] REPENTOGON=true。游戏开始时也会把该版本行写入控制台与日志。

你上传的报错中第502行和第498行回调对应旧v1.65文件布局；当前安装可能仍加载旧文件或混合文件。本版增加明确的运行版本输出，用完整替换和重启排除这一问题。这个报错本身确为模组的类型处理错误，不要求重装忏悔龙。

## 修改

1. 修复MC_POST_ENTITY_REMOVE的CanTriggerStreakEnd报错。该通用回调提供Entity，必须先ToTear后才能访问泪弹字段。同一回调里的大便碰撞检查也使用转换后的EntityTear；伤害来源中的激光以及通用父泪弹在进入专用接口前同样转换。严格类型代理已复现旧代码错误并确认新代码通过。

2. 英灵剑保留飞刀与满血剑气，实际出手触发旋斩。本版在真实原生EntityKnife上开启SetIsSpinAttack/SetIsSwinging，并明确启动原版Spin动画；删除泛用飞刀Shoot调用。使用原生剑素材、动画与碰撞体，不复制贴图、不额外绘制剑影、不用脚本范围伤害模拟旋斩。hunterdiag会显示原生剑动画名称和帧号。官方REPENTOGON文档确认原版Spin素材带Hit1/Hit2空层碰撞信息，但这里没有游戏运行环境，最终显示和原生碰撞仍需游戏确认。

3. 三圣颂维持已要求的原版伤害16倍（此前4倍后又要求再乘4），本次修改实现路径，不继续追加倍率。移除v1.66临时修改玩家Damage并假设它能改变原生基础伤害的方案。REPENTOGON的光束碰撞回调确定准确的激光与目标，在MC_ENTITY_TAKE_DMG中返回Damage覆盖实际伤害，保留原本单段比例、频率及命中方式，且只乘一次。覆盖旧版来源只显示玩家、伤害标记为0的情况；较新REPENTOGON的ExtraSource也可直接识别。角色面板不变，独立硫磺火/科技X环、DOT和其他来源不跟随增伤。hunterdiag中的light显示incoming和applied，例如未修正单段1.4应变为22.4；巧克力牛奶等额外兼容倍率另外计算，原版护甲/减伤仍由游戏处理。未安装REPENTOGON时保留旧的保守来源回退，精确光束归属路径需要REPENTOGON。

4. 诅咒之眼换弹受伤传送：旧代码把回调借用的EntityRef保留到后续帧，再去访问其来源，存在来源失效风险；而且在玩家效果更新期间直接使用传送道具会触发房间切换。现仅保存来源类型、编号、受伤数值、楼层和房间等普通值，确认实际掉血后在全局POST_UPDATE阶段消费一次传送事件。忏悔龙环境下在原生受伤处理前清除主武器的原版诅咒之眼蓄力，避免原版立即传送与自定义传送重复进入。黑蜡烛、付款伤害、护盾取消、死亡、角色变化与已经切换房间时取消待处理事件。此处已消除可确认的代码风险；没有游戏程序/崩溃转储，不能宣称已经复现并验证你遇到的原生闪退本身。

## 验证

通过Lua5.4语法、XML/ANM2解析、实际上传Stats+/EID接口执行、原有伤害/骨心判定及兼容回归。新增严格Entity类型、借用EntityRef失效、延迟且单次传送、原版Spin启动、玩家来源/零标记光束命中、取消伤害的静止靶观察、无重复增伤与其他激光隔离测试。旧v1.66在对应的四类接口契约测试中失败，新版通过。人物视觉资源、数值、Stats+、生命惩罚、剖腹产命中削减逻辑保持原版字节。

这些是接口契约和逻辑模型测试，不是Isaac运行结果。本机没有Isaac可执行文件；原版旋斩、实际靶伤害与诅咒之眼不再闪退，均需在游戏内确认。此前磐石精确射速上限、复杂第三方模组组合等限制继续存在。

若仍异常，请提供hunterdiag输出（须显示v1.67）和展开后的完整报错；若是原生闪退，可附日志最后一段。该命令现在同时报告装载版本、忏悔龙状态、三圣颂输入/输出伤害和原生剑动画，便于直接定位。
